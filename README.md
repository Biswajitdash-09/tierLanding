A modern, responsive landing page and product showcase for **TierChnology**, connecting learning, payroll, payments, banking, and AI-powered financial intelligence.

---

## Products Featured

1. **Studybuddy**: AI-powered EdTech companion for everyday learning and focus.
2. **MyPay**: Fintech platform integrating payroll and checkout workflows.
3. **Strait**: Financial routing and transaction movement infrastructure.
4. **TimBis Bank**: Modern digital banking experience focused on clarity and confidence.
5. **Accountant AI**: AI bookkeeping and business intelligence platform.
6. **Kowo Pay**: Instant mobile payments application.

---

## Tech Stack

* **Framework:** [React 19](https://react.dev/)
* **Build Tool:** [Vite 6](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with custom HSL theme tokens
* **Icons:** [Lucide React](https://lucide.dev/)
* **Routing:** [Wouter](https://github.com/molefrog/wouter)
* **Components:** [Radix UI Primitives](https://www.radix-ui.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)

## Getting Started

### Prerequisites

* Node.js 20+
* pnpm (`npm install -g pnpm`)

### Installation

```bash
# Clone the repository
git clone https://github.com/Biswajitdash-09/tierLanding.git

# Navigate into project directory
cd tierLanding

# Install dependencies
pnpm install
```

### Development Server

```bash
pnpm run dev
```

### Production Build

```bash
# Typecheck and build for production
pnpm run build

# Preview production build locally
pnpm run preview
```
